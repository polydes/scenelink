# Scene Link Extension

[Website/Releases](http://www.polydes.com/repo/toolset/com.polydes.scenelink) |
[Issues](https://github.com/polydes/scenelink/issues)

</div>

This [Stencyl](https://www.stencyl.com/) extension provides an alternative overview of all the scenes in a game, laid out visually relative to each other. It can be useful for designing Metroidvania-style games.

## Using this Stencyl extension

This is a free extension. Installation instructions and guides can be found [here](http://www.polydes.com/repo/toolset/com.polydes.scenelink/).
